## How to Apply

### Method 1: Automatic (Recommended)
1. Open Intro.unity scene
2. Menu: Window > Intro Scene Setup > Apply Atmospheric Polish
3. Done!

### Method 2: Manual
1. Add component "IntroUIPolish" to NarrativeCanvas
2. Create GameObject "IntroLighting" at scene root
3. Add component "IntroLighting" to it

## What Gets Added to Scene

### UI Elements
- TopDialoguePanel: Styled box for narrative text
- ContinuePromptContainer: Styled box for continue prompt
- Decorative separators

### Lighting
- WindowLightStreaks: Cool-toned spot light (window effect)
- WindowLightStreaks_2: Second cool-toned spot light
- CharacterLightGlow: Warm-toned point light above player
