## ⚠️ What You Need To Setup In Unity (20 minutes)

### Step 1: Create Egg ItemDefinition Asset (5 min)
```
1. Right-click: Assets/Items folder
2. Create > Inventory > Item
3. Name it: "Egg"
4. Set Display Name: "Egg"
5. Set Icon: your egg sprite
6. Set Max Stack: 99
7. Save the asset
```

### Step 2: Create Egg Prefab (10 min)
```
1. Create new GameObject: "Egg"
2. Add Sprite Renderer component (egg sprite)
3. Add BoxCollider2D:
   - Is Trigger: ✓ checked
   - Size: (0.3, 0.3)
4. Add PickupComponent (existing script):
   - Speed: 5
   - Pickup Distance: 1.5
   - Collect Distance: 0.1
   - TTL: 30
5. Add EggItem component (optional)
6. Save as prefab: Assets/Resources/Prefabs/Items/Egg.prefab
7. Delete from scene (keep prefab only)
```

### Step 3: Add ChickenController To Chickens (5 min per chicken)
```
For EACH chicken:
1. Select the chicken GameObject
2. Add Component > ChickenController
3. In Inspector, assign:
   - Egg Item: [Your Egg asset]
   - Egg Count: 1
   - Egg Laying Time: 8 (hour of day)
   - Egg Laying Time Window: 1
   - Egg Prefab Path: [Your Egg prefab]
   - Day Night Cycle: [DayNightCycleNice2D]
   - Spawn Offset: (0, 0, 0)
   - Spawn Random Radius: 0.3
4. Done!
```

## 🔧 How It Works (Technical)

### Time Handling
- DayNightCycleNice2D provides `TimeNormalized` (0-1)
- ChickenController converts to 24-hour format
- Example: TimeNormalized = 0.333 → 8 AM
- Script checks if current hour is in laying window

### Spawning
- When time window is reached, egg prefab instantiates
- Spawns near chicken + random offset
- PickupComponent is set up with item data
- Only happens once per day (flagged by hasLaidEggToday)

### Pickup
- PickupComponent detects player within range
- Moves egg toward player using Vector3.MoveTowards
- When close enough, calls InventoryController.TryAdd()
- Item added to inventory, egg destroyed

## 🐛 Quick Troubleshooting

| Problem | Quick Fix |
|---------|-----------|
| Eggs not spawning | Check egg prefab path is `Resources/Prefabs/Items/Egg` |
| Eggs not picking up | Verify PickupComponent on prefab, check player has "Player" tag |
| Inventory shows full | Create or clear some inventory space |
| Eggs disappear too fast | Increase TTL value in PickupComponent |
| Wrong time | Check egg laying time vs game hour calculation |
| Multiple eggs same day | Check for duplicate ChickenController components |

See CHICKEN_EGG_TROUBLESHOOTING.md for detailed fixes with code examples!
